# Sistema de cadastro e bonificacao de novos colaboradores 


Sistema responsavel pelo cadastro de  novos colaboradores. No sistema, devera ser informado o nome do colaborador e seu respectivo salario. o sistema devera retornar uma mensagem de boas vindas dizendo ao colaborador e seu salario base juntamente com o seu salario bonificado com 15%
## Sistema de cadastro de novos colaboradores

## Descrição
A ferramenta foi desenvolvida para registrar o colaborador e já dar um incentivo financeiro logo de cara:
* "Cadastro Rápido:" O usuário informa o seu nome e o valor correspondente ao seu salário base.
* "Bonificação Especial:** Ao completar o primeiro mês, o sistema calcula automaticamente um bônus de 15% sobre o salário inicial.
* "Mensagem de Boas-Vindas:"" O programa exibe uma mensagem personalizada parabenizando o novo talento, mostrando claramente tanto o salário base quanto o valor já bonificado.


## Como funciona 
O funcionamento interno do sistema é bem direto:
1. O programa recebe e armazena o **nome** e o **salário base** do funcionário.
2. Em seguida, ele calcula 15% em cima desse valor inicial.
3. Soma essa porcentagem ao salário original para gerar o **salário bonificado**.
4. Por fim, retorna a mensagem de boas-vindas com todos os dados calculados.


## Como Usar 
Para colocar esse projeto para rodar no seu computador:
1. Abra o **VS Code** e crie um diretório para o seu projeto.
2. Insira o arquivo com o código principal do sistema na pasta.
3. Abra o terminal integrado e execute o arquivo para ver a mensagem de boas-vindas e os cálculos aparecendo na tela.
